## Purpose and Intended Learners

This project teaches **Software and Symbolic AI to beginners** through three connected resources built from one shared Markdown source:
1. **Study Guide**,
2. **PPT Slides**
3. **Video Tutorials**

Intended learners are first-time learners of computer science and AI, including students from non-technical majors.

After working through the material, a learner should be able to:

1. Explain system vs. application software and what an operating system does.
2. Describe how programming languages, software engineering and databases support software development.
3. Understand basic algorithms (searching, sorting, recursion) and data structures.
4. Explain what Symbolic AI is and how it represents knowledge with logic, facts and rules.
5. Describe how rule-based systems and search reach conclusions.
6. Discuss real-world applications, advantages and limits of Symbolic AI.
