## Purpose

This project teaches **Software and Symbolic AI** to beginners. From one shared Markdown source we produce three connected learning resources:

| Resource | Purpose |
|---|---|
| **Study Guide and Test Bank** | Help beginners learn independently through explanations, worked examples, activities, exercises, and references. |
| **PPT Slides** | Explain the important ideas visually. |
| **Video Tutorials** | Walk learners through focused explanations and demonstrations. |

Because all three come from the same Markdown content, terminology, examples, and answers stay consistent. When an explanation changes, the Markdown is corrected first and the affected resources are then updated.

## Intended learners

Beginners with no prior knowledge of software, algorithms, or AI. We assume only basic computer use and school-level maths.

## Learning goals

By the end of this project, learners should be able to:

1. Distinguish system software from application software and describe what an operating system does.
2. Explain how programming languages, software engineering practices, and databases support software development.
3. Describe basic algorithms (searching, sorting, recursion) and common data structures.
4. Explain what Symbolic AI is and how it represents knowledge using logic, facts, and rules.
5. Explain how rule-based systems and search algorithms reach conclusions or solve problems.
6. Identify real-world applications, advantages, and limitations of Symbolic AI.
